# Paket tugas Sastrawan

Paket disiapkan pada 3 November 2026 untuk bagian pencari kerja LangkahKerja.

1. `LAPORAN_SASTRAWAN.md`: bagian laporan yang dapat digabungkan oleh kelompok. Lengkapi identitas akademik dan format kampus dari data asli.
2. `NASKAH_REKAMAN.md`: narasi dan pembagian bagian yang boleh direkam. Sesuaikan panjang narasi bila akan menambahkan voice-over.
3. `VALIDASI.md`: bukti tes, build, ukuran layar, hash APK, dan batas verifikasi.
4. `images/`: bukti tampilan portrait dan desktop.

Deliverable lokal di `outputs/01a14404-1cdb-7073-b5e9-677c2abfa2b4/`:

- `kontribusi-sastrawan.xlsx` dan `.csv`: 12 poin kontribusi untuk Excel kelompok.
- `demo-sastrawan.mp4`: demo per langkah 1:47, tanpa suara, dengan subtitle. Disusun dari tangkapan layar aplikasi nyata, bukan mockup.
- `demo-sastrawan.srt`: subtitle terpisah untuk editor kelompok.
- `paket-sastrawan.zip`: dokumen, spreadsheet, subtitle, gambar, dan video tanpa APK.

APK debug 1.3.0+4 disediakan terpisah di `build/app/outputs/flutter-apk/app-debug.apk` karena ukurannya sekitar 164 MiB. APK untuk pengujian; bukan berkas upload Play Store.

Perubahan kode berada di branch `codex/responsive-demo-handoff` untuk ditinjau lewat PR. Kode utama tidak langsung ditimpa di GitHub. Paket ini belum dikirim ke chat kelompok, dan PR tidak digabung otomatis.
